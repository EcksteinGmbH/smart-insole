# 固件发布包

这里仅存放可以交付或刷机的固件，不放 ESP-IDF 编译中间文件。

当前版本：[`2026-11-04_1605_c5575ca`](2026-11-04_1605_c5575ca/)

- 每次构建按 `<日期_时间>_<固件版本>` 建立独立目录，不覆盖旧版本。
- `01_full_flash/`：日常整机刷机，完整镜像从地址 `0x0` 写入。
- `02_separate_flash/`：bootloader、分区表和应用程序的配套文件及地址。
- `03_test_results/`：只保存与该版本对应的烧录报告和原始日志。
- 开发环境仍从 `firmware/build/` 读取编译产物；不要手工整理或提交该目录。

编译完成后运行 `tools/package_firmware.sh` 自动生成上述目录和校验文件。
