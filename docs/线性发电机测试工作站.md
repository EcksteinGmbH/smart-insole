# 线性发电机测试工作站

## 1. 目标与边界

本工作站用于同一只线性发电机在结构改造前（T0）和改造后（T1）的性能保持性测试：

- 在输出 Pogo Pin 上分别记录开路电压和短路电流；
- 用 WT9011DCL-RF 同步记录手摇过程的三轴加速度；
- 保存原始数据、试验条件和单次 HTML 报告；
- 用加速度估计手摇激励，输出原始读数和激励归一化后的 T0/T1 保持率。

当前版本不会自动读取万用表。每轮采集结束后由操作者输入稳定读数。接线、Pogo Pin 输出是 AC 还是整流后的 DC、以及万用表应选 AC/DC 档，由硬件确认结果决定，并通过命令参数记录。

> 开路电压和短路电流来自两个不同工作点，不能用 `Voc × Isc` 计算输出功率。若后续需要功率，应增加已知负载电阻和负载两端电压测试。

## 2. 硬件与软件

硬件：

- 待测线性发电机；
- 万用表和适合 Pogo Pin 的可靠夹具；
- WT9011DCL-RF 从机及配套 2.4 GHz RF 主机；
- Ubuntu 工作站。

WT9011DCL-RF 不是 BLE 设备。配套 RF 主机通过 CH340 USB 串口连接电脑，默认波特率为 460800。工作站解析默认的 29 字节 `设备 ID + 55 61 + 26 字节数据` 帧。厂商资料：

- [产品说明](https://wit-motion.yuque.com/wumwnr/docs/ydvngreskokcbr1r)
- [规格参数](https://wit-motion.yuque.com/wumwnr/docs/ri6mnara0hw0egpk)
- [通信协议](https://wit-motion.yuque.com/wumwnr/docs/iezbgz4r1uxmeosx)
- [上位机说明](https://wit-motion.yuque.com/wumwnr/docs/xcmc7nkbvlg6losd)

首次安装项目内依赖：

```bash
uv venv tools/.venv
uv pip install --python tools/.venv/bin/python -r tools/requirements.txt
```

查看 RF 主机串口：

```bash
tools/generator_test.sh ports
```

常见设备名是 `/dev/ttyUSB0`。工具会优先自动识别 CH340；存在多个候选串口时必须用 `--port` 指定。

## 3. 正式测试前的准备

1. 固定加速度传感器方向和安装位置。T0/T1 不能改变安装方式。
2. 在厂商上位机中确认 RF 主机能收到从机数据，并记录从机 ID。
3. 传感器使用 ±16 g；建议带宽保持 20 Hz，所有正式试次使用同一配置。
4. 明确 Pogo Pin 输出性质，并在命令中记录 `--waveform ac` 或 `--waveform dc`。
5. 选择万用表对应的电压/电流档。禁用会明显改变读数的自动换档时，需记录固定量程。
6. 统一手摇方向、行程和目标节奏。建议用节拍器，例如 2.5 Hz（150 BPM）。
7. 每个版本、每个工况至少做 5 次有效重复，T0 和 T1 尽量由同一操作者在同一天完成。

短路电流档通常有保险丝和分流电阻。接线及允许的持续时间应以发电机和万用表规格为准；本工具不控制电路，也不能替代电气安全检查。

## 4. 单次采集

每轮包含 3 秒静止、20 秒手摇、3 秒静止。工具在阶段切换时打印提示。

开路电压示例：

```bash
tools/generator_test.sh capture \
  --generator GEN-A \
  --revision T0 \
  --mode open \
  --repeat 1 \
  --port /dev/ttyUSB0 \
  --device-id 0 \
  --waveform ac \
  --meter-model "万用表型号" \
  --meter-range "AC 20 V" \
  --target-frequency 2.5 \
  --operator "姓名"
```

短路电流示例：

```bash
tools/generator_test.sh capture \
  --generator GEN-A \
  --revision T0 \
  --mode short \
  --repeat 1 \
  --port /dev/ttyUSB0 \
  --device-id 0 \
  --waveform ac \
  --meter-model "万用表型号" \
  --meter-range "AC mA" \
  --target-frequency 2.5 \
  --operator "姓名"
```

如果省略 `--meter-value`，采集结束后工具会询问读数。用于脚本批量运行时必须显式提供，例如 `--meter-value 5.16`。开路/负载默认单位是 V，短路默认单位是 mA；必要时可用 `--meter-unit` 修改。

若不知道从机 ID，可先省略 `--device-id`，工具会锁定收到的第一个 ID。正式测试中建议明确记录 ID。

## 5. 数据输出

默认目录结构：

```text
test_runs/
└── GEN-A/
    └── T0/
        └── 20261026_153000_open_r01/
            ├── manifest.json       # 样品、工况、仪表和采集配置
            ├── imu_raw.csv         # 带主机时间戳的原始 IMU 数据
            ├── summary.json        # 完整机器可读分析结果
            ├── trial_summary.csv   # 一行式汇总，便于导入表格
            ├── acceleration.svg    # 本次主运动轴曲线
            └── report.html         # 人可读单次报告
```

`test_runs/` 默认不进入 Git。正式归档时，应将需要保留的试次目录复制到受控的项目文档或试验数据存储位置，并连同接线照片、万用表屏幕照片和样品编号保存。

核心指标：

- 主运动轴：活动阶段中标准差最大的 X/Y/Z 轴；
- 主轴加速度 RMS：去均值后的主轴振动强度；
- 主频：0.5–8 Hz 范围内的主要手摇频率；
- 速度激励指标：`加速度 RMS / (2π × 主频)`；
- 归一化电气指标：`万用表读数 / 速度激励指标`。

速度激励指标基于近似周期运动，仅用于同一夹具、方向和流程的相对比较，不是发电机内部真实速度，也不能作为效率值。

以下情况报告会标为“需复测”：

- 活动阶段少于 5 秒或有效数据少于 10 帧；
- 超过 5% 的采样间隔出现明显掉帧；
- 任一加速度轴接近 ±16 g 量程上限。

重新分析已有试次：

```bash
tools/generator_test.sh analyze test_runs/GEN-A/T0/20261026_153000_open_r01
```

## 6. T0/T1 对比

完成新结构后，保持相同传感器、安装位置、节拍、万用表设置和操作者，使用 `--revision T1` 重复开路与短路测试。

生成聚合报告：

```bash
tools/generator_test.sh compare \
  test_runs/GEN-A/T0 \
  test_runs/GEN-A/T1 \
  --output-dir test_runs/comparisons/GEN-A_T0_T1
```

对比输出 `comparison.json`、`comparison.csv` 和 `comparison.html`。默认判定条件为：

- 每个版本、每个工况至少 5 次有效重复；
- 归一化电气指标保持率 ≥ 90%；
- T0、T1 的归一化指标 CV 均 ≤ 15%。

门槛可用 `--minimum-trials`、`--minimum-retention` 和 `--maximum-cv` 调整。门槛属于当前工作站的初始建议，不是已批准的产品验收标准；正式测试前需由产品/工程负责人确认。

原始读数与归一化读数都必须查看：若原始值下降但归一化值不降，通常表示 T1 手摇激励较弱；若二者都下降，则更支持结构导致性能变化的判断。短路状态可能改变电磁阻尼，因此开路和短路必须分别比较，不能共享同一轮加速度。

## 7. 无硬件验证

模拟一轮 2.5 Hz、3 g 的测试：

```bash
tools/generator_test.sh simulate \
  --generator DEMO \
  --revision T0 \
  --mode open \
  --repeat 1 \
  --meter-value 5.16 \
  --frequency 2.5 \
  --amplitude-g 3
```

模拟模式只验证目录、分析算法和报告生成，不能验证串口、电气接线或实物性能。

## 8. 历史资料的使用方式

仓库中的旧 PPT 记录过约 5.160 V 开路电压和 26.100 mA 短路电流，也包含整流桥、电容及不同负载的测试。由于旧资料没有完整的原始加速度、统一手摇条件和本次 Pogo Pin 接线定义，这些数值只能用于量级检查，不能直接作为 T0 正式基线。正式基线应使用本工作站重新采集。
